# Default-off native mixed row reuse: finite runtime integration

Scope is one fresh mixed admission only. DRAMA3_MIXED_ROW_REUSE=1 requires the existing mixed backbone, span256 and fused native MoE residual. All default paths remain available. Five graphs are captured before readiness: (D64,P768,S256,K576), (64,1024,256,832), (64,1280,256,1088), (64,1536,256,1088/1344). ceil64(unique) is the minimum capacity requirement; the selector chooses the smallest prebuilt K that covers it. Unsupported shapes, no sufficient aliases or too many unique rows fall back to the original graph. At least256 original rows must be removed.

Exact ownership uses full11-column integer rows through the first unequal row. Pairwise NumPy equality has no digest/hash. The longest matching previous prefix is copied through already canonical owners, so there are no alias chains. Every decode row and every original padding row retains its own owner. Added compact padding duplicates original row0, already present. All backbone attention/GDN and teacher updates remain independent at original positions and slots; only stateless MoE work is reused. Prompt histories and reference conditioning are included in the full encoded causal rows; equal current token alone never suffices.

Plans retain immutable full prompt bytes. MixedGraph.prepare compares all lengths/types/full bytes before writing graph metadata, rejecting a same-length stale-conditioning plan, inference tensors without version counters, and NumPy external writes. The plan is consumed immediately with the same prompts; no inter-admission model-state/prefix cache exists.

MixedGraph holds one persistent packed keep/inverse GPU array and one compact-slots array. CPU metadata is uploaded once during prepare. After row_metadata and prefill-state reset, slots are gathered once before L0. Each layer gathers its normalized input, executes unchanged model.moe_parts(fulltop8/nativeprecisions), and the next combine reads compact outputs through inverse while updating the original full residual/output rows. Kernel arithmetic is AST-identical to native after removing address indirection; explicit BF16 FMA/rounding/FP32 RMS reduction and compiler flags remain unchanged. Gate row stride remains its actual packed stride.

Unlike the earlier artifact, compact input and norm outputs now allocate inside the shared CUDA graph pool. They remain live through their native consumers, all on the existing model stream; mixed backbone rejects shared-expert overlap. Persistent maps never use that temporary pool. MixedGraph.run still clones both returned hidden outputs before another graph can reuse shared-pool storage. This memory change requires a new complete production exact gate; earlier603/2430 passes do not establish it.
